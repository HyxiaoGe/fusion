# 语义正则迁移第六阶段：天气疑问范围补修

## 触发证据

- 第五阶段 PR #152 的 API 镜像在 dev 与发布台账核对一致。原句天气 run `c87c9b82f6f5465b998c671ce82cdf1f` 中，`weather_forecast` 成功，模型候选写出“因此无法确认上午是否下雨”；最终仍因 `weather_fact_mismatch` 退回多日事实兜底，未直接回答用户上午避雨诉求。
- 逐句核对显示温度、风力和“白天多云”均与结构化返回一致。误拦发生在“下雨”：旧校验器因同一分句中更早的“无法确认”而拒绝豁免后面的“是否下雨”。

## 修复与验证

- 只检查距离天气词最近的“是否／能否／会不会／能不能”之后、天气词之前是否已有免责；疑问词之前的限制说明不再影响该疑问。疑问后跟“但会下雨”的肯定断言仍进入事实核对并拒绝。
- 新增真实句式和相反断言回归；天气校验器 73 项通过。第五阶段真实模型候选及其持久化结构化天气结果在本地新代码重放，`is_valid=True, reason_code=ok`。独立只读复审未发现本轮新增的具体错误放行或误拦。
- 完整 3254 项 unittest 通过、2 项跳过；额外 pytest 清单 241 项通过；架构、本次改动文件 Ruff／格式和差异检查通过。PR 必需检查、dev 发布台账和运行镜像、同句真实 API 与原有 Chrome 登录页面均待核；本地重放不等于线上效果。
