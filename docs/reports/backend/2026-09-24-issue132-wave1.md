## 退出第一波的判据与单独留档

- `_VERIFIED_SOURCE_RE` 的字面选包消费者及定义簇七条正则均还原。较早的宽候选移除这些职责时，`mcp_alias-03` 一次盲测加三次定向重复均为候选 `model / clarification_only`，基线均为 `literal / verified_web`；`What is a current price?` 也出现 `clarification_only`。这说明复合查证请求上的字面选包承担真实职责。n=4 只用于排除一次偶然输出，不推算总体失败率；应带入 2b 与 #110 方向复核。重复记录见 [targeted-repeats.jsonl](2026-09-24-issue132-wave1-targeted-repeats.jsonl)。
- 问候正则也退出第一波：在恢复前的一轮 47 条配对中，`direct-01「你好呀」` 基线 `literal/direct`，候选模型超时后为 `failed/clarification_only`。原始全轮记录见 [before-greeting-restore.jsonl](2026-09-24-issue132-wave1-before-greeting-restore.jsonl)。恢复后最终轮的该条两臂均为 `literal/direct`。不把超时解释为稳定语义错误，但它已经违反了本轮 package 零变化放行条件。
- 产品意图 P-b、18 条跨组项、`_VERIFIED_SOURCE_RE` 选包、定义簇、问候、其余承担 URL/新鲜度职责的 Q 判据均未删除。`_VERIFIED_SOURCE_RE` 的跨组消费者保留；`_RELATIVE_DATE_RE` 与 `_URL_RE` 未改。
