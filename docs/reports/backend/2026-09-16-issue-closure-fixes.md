## 任务范围与实现

### #30：总结阶段的零有效证据事实边界

旧守卫把失败搜索等同于证据，又仅扫描阿拉伯数字，中文金额、中文时长、发车时刻和纯文字结论可以穿过。修复将冻结的能力包贯穿 call_config、runtime 和 summary request；明确需要外部事实的任务，在无有效证据时先缓冲再输出诚实答复，并记录 `incomplete`。正常 direct、transform、date 不套该守卫。知识库与深度研究继续走各自的专属校验。

证据不再仅按块类型判定。失败、空产品结果、附件引用以及行程引用视图都不能单独放行。成功或有实质内容的降级产品结果仍可用；成功的网页恢复路径保留。独立审查进一步复现并修复了“搜索/读页 success 但仅有 URL”的空来源：流式准入、提示词和答案提交统一读取本轮 `state.recovery_evidence` 中的实际内容记录，不能用来源卡片的标题、URL 或 success 状态替代正文。缺失运行期记录的旧调用也不能凭网页元数据放行。

本次边界是“总结阶段没有有效证据”，不是新增逐句事实校验器。有来源不代表每一句话都获来源支持，也不代表产品任务整体完成。

### #58：推荐问题送达窗口与前端轮询

采用原 issue 接受的封口前送达方案。正文与 `run_completed` 先行送达，辅助模型调用增加应用层 8 秒截止时间，SSE 尾部等待覆盖该预算并留 1 秒写回余量。没有重开封口后的流，也没有另建旁路通道。

前端在本会话、本条消息对应的 SSE streaming/reconnecting 且推荐 pending 时等待结果事件；focus/visibility 不抢跑会话详情。流结束仍 pending、刷新恢复、旧后端兼容继续走有限轮询。保留本地 placeholder 与服务端消息 ID 映射。

生成异常、超时或空正文明确为 `failed`，保留上一批问题，不再填入通用问题后标成 ready。成功换批仍走原接口，revision/seed/CAS 语义保留。旧任务失败不能覆盖更新 revision。辅助等待被取消后仍以原 task_id 封口，独立生成任务继续；lifecycle 不再把已经发出终态的正文重复写成 interrupted。

代价：SSE 尾部最长额外等待约 9 秒。正文终态先到达，但输入框沿用现有 isStreaming 行为；部署验收需观察等待期间继续发问、停止与切换会话的体验。超出整个窗口仍可能进入恢复路径，不宣称所有网络和数据库异常都可实时送达。

### #57：品牌保留与安全兜底语言

逐供应商正则会把“高德置地广场”改为“地图服务置地广场”，也会损坏英文品牌实体。删除品牌字符串替换和实体占位机制，保留兼容调用接口与内部工具标识脱敏。供应商中性表达继续由既有模型提示词约束；服务端不再强制删除品牌。回归覆盖品牌原文、结构化实体、SSE/持久化一致性和实际输出归因。

工具失败、无有效证据和协议错误三条安全兜底已支持 12 个语言选项（含简繁中文），文案集中在 `runtime_prompts.toml`。原始用户请求从执行入口冻结，常规结束与总结阶段共享语言选择缓存；初始、重试和续跑都沿用真实原请求，工具结果及内部控制消息不参与语言选择。

正常回答不新增模型调用。只有安全守卫触发且语言尚未确定时，才使用辅助模型选择一个受限 locale；正文始终取本地模板，模型不能生成兜底事实。该选择不重试，复用既有辅助模型的 512 token 预算，最多占用剩余运行预算内的 8 秒；同步模型目录解析移到线程，并与模型调用共同受应用层截止时间约束。明确的 `options.response_language` 可直接选择支持的模板。已经确定的语言无需剩余模型预算。

独立审查发现并修复了协议兜底的保存分叉：此前可能 SSE 发英文而保存旧中文，现在持久化统一使用实际交付正文。`incomplete` 与输出归因保持真实。

边界：语言选择失败、未知语言或预算耗尽且尚无语言结果时，使用兼容的简体中文默认文案。不能保证模型完全不可用时仍理解自然语言切换要求；当前覆盖上述三条通用安全兜底，不宣称所有产品卡片、知识库或深度研究专用文案均已国际化。

以下质量证据仍未完成：真实模型的语言选择准确率，以及原 issue 提到的主体、数量口径和未知状态回答质量回放。本轮没有以 mock 返回值证明模型识别正确，也未调用付费模型做验收。因此不把 #57 标为全量质量完成。

## 部署后的关闭条件

1. 自然出行请求缺乏有效工具结果时，用户消费到的正文、持久化内容、终态与刷新结果都应诚实一致；验证有证据恢复及普通改写不受影响。
2. 真实推荐生成耗时超过 2 秒时，浏览器消费到 `pending → ready/failed → done`；首批展示前没有为推荐轮询详情，刷新恢复同一 revision，换批内容实际变化。
3. 验证推荐等待期间停止、新请求接管、断线恢复、失败、迟到 CAS；区分 run 已完成与网络流尚在发送辅助结果。
4. 用自然问题验证语言选择（含明确要求切换语言、引用材料和工具语言冲突）、失败文案与刷新一致性；完成 #57 的真实回答质量回放。本地契约测试不替代这两项模型验收。
