## 本次补修

- 站名提取识别“出发站为／到达站均为”的实际站名；数值差异词只作用于它前面的数值或紧邻的“元差价”等直接差值表达，不再让后置“略快”把已有票价判为差值。本地用第三阶段高铁模型末轮和持久化结果块重放，新代码已放行正确候选。
- 天气地点核对只豁免通用“行政区／按行政区”标签，仍拒绝“福田区行政区”冒充返回的南山区；肯定回答“上午是否下雨：是”继续进入返回事实校验。模型提示词要求聚焦所问日期和条件、简短说明昼夜粒度，不扩写未返回的无雨、无雷雪大风和未请求的温差。
- 地点工具说明要求本次每次指定行政区搜索都保留区名；模型回答不得凭商圈密度推测推荐地点或推断步行距离。此项依赖模型遵循，需真实 API 复验。
- 独立代码复审发现行政区过宽豁免、疑问句跳过肯定结论、后置差价错误放行三个反例。相应失败先行测试已加入并修复；后置旅行差价仍保守拒绝，避免把未绑定候选的差价误当票价。
