# #132 2a：产品工具否定进入模型选包后的执行链

时间：2026-09-24（Asia/Shanghai）。基线 `master@5f20d19e`，候选为本工作树。2a 未删除产品选包判据，2b 未启动。

## 前提与实现证据

- **本机受控模型响应实测**：对“不要查航班，帮我看看高铁”，模型分类器调用 1 次并返回 `travel_air_rail`，基线 `capability_resolution.external_tool_names=[web_search,url_read,search_flights,search_trains]`。因此模型选包后的产品细粒度否定确实漏执行。受控响应只验证后续执行链，不当作真实模型自然输出。
- **代码阅读**：`unavailable_tool_names` 来自“授权但未提供 schema”的工具，在路由器中触发 `required_tools_unavailable`；它不是用户显式禁用。2a 新增 `denied_product_tool_names` 字段，否定解析与候选包无关；可用性判断与公告生成都排除被禁用的工具。
- **本机实际 call-config，受控模型候选**：相同输入得到 `package_id=travel_air_rail`，`denied_product_tool_names=[search_flights]`，`external_tool_names=[web_search,url_read,search_trains]`，`announced_tools` 同样不含 `search_flights`。显式“不要调用 search_flights”结果相同；“别查航班，算了还是查一下航班吧”最终允许。
受控模型候选对应的内存中 `RunCapabilityResolution` 对象摘要（本机取数，未部署；`denied_product_tool_names` 不进入持久化序列化）：

```json
{
  "package_id": "travel_air_rail",
  "reason_codes": ["air_rail_comparison"],
  "external_tool_names": ["web_search", "url_read", "search_trains"],
  "denied_product_tool_names": ["search_flights"],
  "effective_plan_mode": "auto",
  "include_current_date": true,
  "network_boundary_required": false
}
```

- **dev 容器真实模型**：指定原句两臂均自然选择 `train`，最终 `external_tool_names=[web_search,url_read,search_trains]`。候选的 `denied_product_tool_names=[search_flights]`；这条真实模型输出不具备区分修复是否生效的能力，区分证据是上面的受控 `travel_air_rail` 候选。

## 顺序语义与边界

- 基线对“查一下航班，算了别查了”返回允许，候选返回禁用；“别查航班，算了还是查一下航班吧”最终允许。末句省略领域词时，仅在同句前文已有该产品工具的正向请求后补一个撤回事件；单独“算了别查了”不会凭空禁用产品工具。
- `_is_product_tool_finally_denied` 的位置排序与 scope matching 代码未改，既有 P-b 与 P/N 正则未删改；这项是为满足本轮给定的顺序原句而补的 N 侧解析。

审查补充的四条对抗样本在本机直接调用否定解析，实际输出如下。第三条末句撤回的是前面的并列查询，因此航班和天气都禁用；这是本轮采用的语义。

| 输入 | 末句省略撤回命中 | `denied_product_tool_names` |
| --- | --- | --- |
| 帮我查下航班的价格，算了别查了 | true | `search_flights` |
| 帮我查高铁，别的不用了 | false | 空 |
| 查一下航班和天气，算了别查了 | true | `search_flights`、`weather_forecast` |
| 算了别查了 | true | 空；同句前文没有正向产品请求 |
