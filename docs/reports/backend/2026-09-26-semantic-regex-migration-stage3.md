# 语义正则迁移第三阶段：真实 API 复验补修

## 触发证据

- 第一、二阶段已完成 PR、CI 和 dev 部署；真实 API 验收分别发现禁网天气回答补充无来源气候数值、正确车次比较被残留票价词面规则误拦、天气跨日期汇总触发逐值校验误拦，以及地点空格短语被改写为高德 OR 查询。原始 run 和结果详见[阶段一报告](2026-09-26-semantic-regex-migration-stage1.md)与[阶段二报告](2026-09-26-semantic-regex-migration-stage2.md)。

## 本次改动

- 沿用现有无工具边界提示词，要求无相关工具或用户来源时不补充典型天气、数值范围等具体事实；天气产品回答聚焦用户询问日期。两项是模型行为约束，静态检查不能证明实际回答正确。
- 地点搜索保留空格短语，只将逗号、顿号等显式备选分隔符转换成高德 OR；工具说明要求模型保留用户指定的行政区。
- 移除把所有“票价”字样当作无依据实时断言的词面拦截，保留与返回候选直接核对的金额、最低价及明确价格比较校验；预算金额只在对应用户原文和相邻预算标签支持时豁免。对“但、且、并、括号”等分开的正面断言和“不含余票”限制语分别核对，避免限制语遮住无依据准点率。
- 独立代码复审提出的缺价候选、无单位与人民币符号错误金额、错误最低价、预算金额冒充票价、同句限制语遮盖等反例，均先写失败回归再修复。已有结构化事实兜底与其正向用例继续保留。

## 验证与发布状态

- 本地架构、Ruff、格式及差异检查通过；按 CI 收集入口完整运行 3250 项 unittest 通过、2 项跳过，额外 pytest 清单 241 项通过。独立代码复审发现的回归均已补失败先行用例并复测；静态复审与本地门禁不等于 dev 真实 API 结论。
- PR、dev 部署身份、同句真实 API 复验和用户现有 Chrome 页面验收仍待记录。此前模型原始提示词探针只说明提示词有可能产生合适答复，不代表 Fusion API 已通过。
