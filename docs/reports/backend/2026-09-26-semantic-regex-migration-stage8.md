# 语义正则迁移第八阶段：范围外日期说明

## 真实触发

- 第七阶段已经发布，原句天气 run `8640a8181cf54afd8f38677f168d28f7` 不再被误拦，直接回答“上午不下雨无法确认”。
- 范围外日期 run `96b827f07d3b486d85d6419787f4dc3c` 询问 2026 年 10 月 20 日深圳是否下雨。天气接口只返回 9 月 26—29 日；模型候选明确说该日超出预报窗口，但旧覆盖句规则仅接受少数完整句式，把自然限制说明判为 `weather_fact_mismatch`。候选还附带未返回的历史平均气温，触发 `unsupported_claim`；最终兜底输出四日预报，未回答目标日期。

## 补修与边界

- 移除“出现覆盖词和日期但未完全套入模板便一律拒绝”的泛化门禁。对可解析的“只返回／未覆盖”等日期主张，仍抽取具体日期范围并与结构化返回集合核对；正确的范围说明后若夹带其他内容，继续进入后续事实校验，不把前缀当作整句豁免。
- 结果模型在目标日期无可用预报时只回答无法确认和已返回日期范围，不附加其他日期逐日天气、历史平均值或出行建议。提示词约束需要真实模型复验，不能把静态文本当成运行证明。
- 独立复审发现的“已返回日期却说未覆盖”、句首短语、同句矛盾及“没返回／暂无”词形加入回归。结构化日期提取仍只能覆盖明确支持的表达；其他自然语义由模型处理。
