# 语义正则迁移第九阶段：明确日期的天气兜底

## 真实触发

第八阶段 dev API run `6b2975641cec41a8a467f0266d42df58` 查询 2026 年 10 月 20 日深圳是否下雨。天气工具只返回 9 月 26—29 日。结果模型先说明无法确认目标日，又附上历史平均气温等无关信息，因而未通过产品事实校验；确定性兜底只列出四日天气，没有回答用户指定的日期。

## 改动与边界

- `weather_forecast` 增加可选 `requested_date` 参数。模型只在用户明确要求单个、带年份、肯定目标日期时传入 ISO 日期；工具只校验日历格式，并将其随本次结果传给模型、保存到天气结果块，不传给天气供应商，不写进按行政区共享的预报缓存。
- 结果模型回答无法交付时，若本轮只有一个天气结果块且该目标日期不在连续返回的预报日期里，兜底直接说明返回范围和目标日无法确认。旧结果块或模型未给明确日期时仍使用既有天气摘要。
- 初稿曾从用户文本抽取唯一日期；独立复审给出“不要查 8 月 20 日，看看未来几天”的实际反例。该实现已撤回，最终代码不根据日期词面判断查询意图。保留的日历格式校验和返回日期集合比较是结构化事实检查。
