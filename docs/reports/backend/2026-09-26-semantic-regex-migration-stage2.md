# 语义正则迁移第二阶段：产品答案

## 范围与边界

基于第一阶段合并提交 `676c9fed`，移除产品答案校验器中推断邻近、体验、排序范围、天气活动效果和建议的措辞正则，以及天气活动、混合交通、单类交通比较的确定性早退。现有最终回答模型根据结构化结果和 `product_results` 轮次提示词回答用户；服务端保留格式、实际返回实体、时间、数值、候选归属及天气字段等可直接核对的事实校验。校验失败或证据不可用时，只交付返回字段的事实兜底。

原先兜底中的天气建议和路线选择建议已移除，跨交通方式的最低价／最短计划时长仍按结构化数值直接计算。硬事实校验新增“可选／推荐”后机场或车站的实体提取，错误机场的回归先失败再通过；“推荐从／可选到”已返回实体正例通过。`no_usable_evidence` 观测路径补齐，旧观测路径只为历史统计兼容保留。

## 后续补修与限制

- 后续补丁处理已复现的票价词面误拦与地点空白词改写，并通过提示词约束无来源气候数值、让天气回答聚焦用户请求日期。提示词能否稳定纠正实际回答，仍需 PR/CI、dev 发布和同句复验确认。
