# 语义正则迁移第二阶段：产品答案

## 范围与边界

基于第一阶段合并提交 `676c9fed`，移除产品答案校验器中推断邻近、体验、排序范围、天气活动效果和建议的措辞正则，以及天气活动、混合交通、单类交通比较的确定性早退。现有最终回答模型根据结构化结果和 `product_results` 轮次提示词回答用户；服务端保留格式、实际返回实体、时间、数值、候选归属及天气字段等可直接核对的事实校验。校验失败或证据不可用时，只交付返回字段的事实兜底。

原先兜底中的天气建议和路线选择建议已移除，跨交通方式的最低价／最短计划时长仍按结构化数值直接计算。硬事实校验新增“可选／推荐”后机场或车站的实体提取，错误机场的回归先失败再通过；“推荐从／可选到”已返回实体正例通过。`no_usable_evidence` 观测路径补齐，旧观测路径只为历史统计兼容保留。

## 分层证据

- 架构、Ruff、差异检查通过；与第一阶段组合后，按 CI 收集入口运行 3245 项 unittest 全通过、2 项跳过；CI 额外 pytest 清单 241 项通过。
- dev 同一 LiteLLM 代理别名 `deepseek-chat` 使用当前 `product_results` 提示词，对天气上午骑行、单类车次最低价／最快、航班加高铁比较各运行两次。修正探针夹具中的时刻与时长矛盾后，答复对齐返回事实、时段粒度和候选范围，未见越界推断。此为提示词层实测，不包含 Fusion API 的工具结果投影、最终答案校验或持久化。
- 三类提示词 SHA-256 分别为天气 `864102fbf7758f3e94d05c5077088ec041b52954a9b2a821c1cdb058feaef6ab`、单车次 `92611ee6c202b89ad97105d78cc80750c4724cca7465f2de69789555aa1b3a8a`、空铁 `b57368db5134489554612aeea77e2c04e5de65428e5a256881b336f311287ce2`。代表答复：天气明确“无法确认上午不下雨”；车次在返回三项中判定 G103 最低参考价、G105 最短计划时长；空铁在返回两班航班与三班高铁中判定 G103 最低参考价、HU7890 最短计划时长，并明确不比较接驳。
- 固定语义反例语料用于说明迁移后的职责边界：本地事实校验会放行某些措辞上的不当推断。测试只核对模型轮次提示词包含对应约束，不把静态检查当语义准确率。
- 独立静态复审未发现确定性可达的 P0/P1；发现的“推荐从北京南站”误拦已补正向回归修复。实际模型偶发越界仍是发布后需要持续观察的风险。
