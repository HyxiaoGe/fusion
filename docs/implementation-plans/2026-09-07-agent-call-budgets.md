3. MCP 每服务每 Run 默认提高到 64 次；其他供应商特有配额不因 Firecrawl 额度充足而无限扩大。
4. 检查较长 Run 的 Redis 所有权与流状态有效期，避免新预算被更早的固定过期时间抵消。
   续跑会创建新 Run，使用当前预算；保留旧 Run 记录、原计划模式和任务策略，不继续继承已经调低的历史预算。
